## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

The Leaflet map lives in `app/Components/map.jsx` and is dynamically loaded by `app/page.js` with server-side rendering disabled. Keep Leaflet imports in the map component because Leaflet requires browser APIs such as `window`. The map also imports Leaflet's stylesheet and sets an explicit container height.

On opening the map, your browser requests location permission and the map centers on your location when it is available. Use **Center map** to locate yourself again. Geolocation requires HTTPS (or localhost). If permission is denied or your location cannot be determined, an error appears on the map and the current map view remains available.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
